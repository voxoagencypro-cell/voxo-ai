# VOXO AI V2 — Design bleu premium

Projet Next.js 15 / React 19 / TypeScript / Tailwind CSS / Framer Motion.

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvrez ensuite `http://localhost:3000`.

## Refonte incluse

- Hero sombre bleu fidèle à la maquette validée
- Logo VOXO AI avec onde vocale
- Téléphone animé et conversation de démonstration
- Colonne des fonctionnalités 24h/24
- Bandeau des secteurs suisses
- Section claire « Comment ça marche »
- Tarifs, FAQ, secteurs et appels à l’action harmonisés
- Responsive mobile, tablette et ordinateur
- Pages existantes conservées : démo, tarifs, contact, checkout et onboarding

## Intégrations à connecter ensuite

Retell AI, n8n, Google Calendar et Stripe sont à brancher avec les clés et webhooks du projet.
